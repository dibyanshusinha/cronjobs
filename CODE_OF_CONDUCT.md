# Code Of Conduct

## Our Pledge

We want this project to be useful, respectful, and welcoming. Participants are
expected to communicate with patience, assume good intent, and focus critique on
ideas and code rather than people.

## Expected Behavior

- Be respectful and constructive.
- Give clear technical feedback.
- Accept that maintainers may choose a smaller scope for the project.
- Avoid sharing private job data, credentials, or security-sensitive details in
  public issues or pull requests.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Publishing someone else's private information.
- Publicly disclosing vulnerabilities before maintainers have had a reasonable
  chance to respond.
- Repeatedly pushing a discussion after maintainers have made a decision.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
or block participants who violate this code of conduct.
